# Mahnoor Khan · Portfolio

Personal portfolio website: selected client work (Tekjee, Myst Hookah Lounge), experience and skills.

Plain HTML/CSS/JS, no build step. Open `index.html` in a browser to view it.

**Live site:** https://mahnoor2404.github.io/Portfolio/

## Publish on GitHub Pages
1. In this repository, go to **Settings → Pages**.
2. Under **Build and deployment**, set the source to **Deploy from a branch**, choose **main** and **/ (root)**, then save.
3. After a minute or two the site is live at `https://mahnoor2404.github.io/Portfolio/`.
