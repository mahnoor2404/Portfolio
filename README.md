# Mahnoor Khan · Portfolio

Personal portfolio website: selected client work (Tekjee, Myst Hookah Lounge), experience and skills.

Plain HTML/CSS/JS, no build step. Open `index.html` in a browser to view it.

## Publish on GitHub Pages
1. Create a new public repository named `mahnoor2404.github.io`.
2. Upload `index.html`, `README.md` and the `assets` folder.
3. Go to **Settings → Pages**, set the source to **Deploy from a branch → main → / (root)**, and save.
4. After a minute the site is live at `https://mahnoor2404.github.io`.
